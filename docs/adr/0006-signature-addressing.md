# 地址只用特征码，缺失时停用而不是崩溃

所有游戏地址都用特征码定位，唯一来源是 `core/src/game/signatures.inc`，加载器、`DDCore` 和 `tools/check_sigs.py` 共用。基准是 guest 的 Steam 版，离线版能兼容就兼容，不当作目标。

失败时分级降级，不能因为新功能让游戏起不来：

- 核心特征码（P1 的核心项和事件总线本体）缺失时，`DDCore` 整体停用，日志写明缺了哪些，旧式 DLL 不受影响。
- 可选特征码（`OPT`，Query 和各语义 hook）缺失时，只有依赖它的主题不可用，订阅返回失败。
- exe 哈希未知但特征码全部命中时只警告。

## 后果

游戏更新后先跑 `tools/check_sigs.py` 离线校验，再启动游戏。
