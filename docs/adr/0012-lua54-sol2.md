# Lua 5.4.9 + sol2 3.5.0，不用 LuaJIT

脚本引擎用 Lua 5.4.9 和 sol2 3.5.0，静态链接进 `DDLua.dll`。游戏是回合制，事件频率低，用不上 JIT；5.4 有整数类型、`<close>` 变量和分代 GC，官方仍在维护，沙箱和字节码限制都容易做。

## 考虑过的方案

LuaJIT 带 FFI，脚本可以直接读写任意内存，和「脚本比 DLL 安全」的定位冲突（见 [0014](0014-sandbox-no-raw-memory.md)）；JIT 申请的可执行内存也更容易触发杀软。手写 C API 绑定可行，但工作量比 sol2 大得多。

2026-11-09 敲定。
